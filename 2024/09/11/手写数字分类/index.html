手写数字分类

发表于2024-09-11|更新于2024-09-11

实验目的

用PyTorch实现MNIST手写数字识别：0-9手写数字识别

导入包

数据集

MNIST数据集是机器学习领域中非常经典的一个数据集，由60000个训练样本和10000个测试样本组成，每个样本都是一张28 * 28像素的灰度手写（通道数为1，彩色图片的通道数为3-rgb）数字图片。

数据集的导入和预处理

直接下载下来的数据是无法通过解压或者应用程序打开的，因为这些文件不是任何标准的图像格式而是以字节的形式进行存储的，所以必须编写程序来打开它

transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize
((0.1307,), (0.3081,))])

预处理数据，归一化操作，它的含义是将图像值都转换到[-1,1]之间:

  • transforms.Compose()
    • 即组合几个变换方法，按顺序变换相应数据。
  • transforms.ToTensor()
    • 转换一个PIL库的图片或者numpy的数组为tensor张量类型；转换从[0,255]->[0,1]
    • 通俗一点的解释就是做了两件事1.改变的导入数据的数据类型，这里是变成了torch.tensor数据类型2.把图片每个像素点的值从0-255
      转换成0-1（用每个值除以255来实现），即用0为黑色，1为白色，01中间的数值表示灰色，越靠近两边颜色越纯净
  • transforms.Normalize((0.1307,), (0.3081,))
    • 通过平均值和标准差来标准化一个tensor图像，可以加快模型的收敛，公式为：
      output[channel] = (input[channel] - mean[channel]) / std[channel]

** 这里有一个讨论 **
提问：ToTensor 已经[0,1]为什么还要(0.1307,), (0.3081,)？那么归一化后为什么还要接一个Normalize()呢?Normalize()是对数据按通道进行标准化，即减去均值，再除以方差

解答：数据如果分布在(0,1)之间，可能实际的bias，就是神经网络的输入b会比较大，而模型初始化时b=0的，这样会导致神经网络收敛比较慢，经过Normalize后，可以加快模型的收敛速度。
因为对RGB图片而言，数据范围是[0-255]的，需要先经过ToTensor除以255归一化到[0,1]之后，再通过Normalize计算过后，将数据归一化到[-1,1]。
是否可以这样理解：
[0，1]只是范围改变了， 并没有改变分布，mean和std处理后可以让数据正态分布

创建CNN模型

由卷积层X2，池化层X2，激活层X2(ReLU)，view层，全连接层X2(Linear)构成
分成四大组(Sequential)：第一组(卷积层1，激活层1，池化层1)，第二组(卷积层2，激活层2，池化层2),第三组(view)，第四组(全连接层1，全连接层2)

下面我将每行代码分为基础知识和加上参数后代码内容的理解两部分，先了解函数的作用，然后带上本例实际运用的参数，感受一张图片是如何被识别分为成0-9的数字的。

torch.nn.Module类和torch.nn.Sequential

nn.Module类

卷积层基础知识

> 函数作用：定义一个卷积核，方便后面进行二维卷积操作

class torch.nn.Conv2d(in_channels, 
                      out_channels,
                       kernel_size,
                        stride=1, 
                        padding=0, 
                        dilation=1, 
                        groups=1, 
                        bias=True)

- in_channels 代表输入特征矩阵的特征图的深度即channel，如输入一	张RGB彩色图像，那in_channels=3

- out_channels 代表卷积核的个数，使用n个卷积核输出的特征图的深度	就是n

- kernel_size 代表卷积核的尺寸，输入可以是int类型如3 代表卷积核的	height=width=3，也可以是tuple类型如(3, 5)，代表卷积核的	height=3，width=5

- stride 代表卷积核的步距默认为1，和kernel_size一样输入可以是int	类型，也可以是tuple类型

- padding 代表在输入特征图四周补零，默认为0，同样输入可以为int型	如1 代表上下方向各补一行0元素，左右方向各补一列0像素（即补一圈	0），如果输入为tuple型如(2, 1) 代表在上方补两行下方补两行，左边补	一列，右边补一列。padding[0]是在H高度方向两侧填充的，padding[1]	是在W宽度方向两侧填充

- bias 表示是否使用偏置（默认使用）

torch.nn.MaxPool2d(kernel_size=2) 二维池化层

  1. nn.Linear的使用:

  2. nn.Linear()的初始化：

    • in_feature： int型, 在forward中输入Tensor最后一维的通道数
    • out_feature： int型, 在forward中输出Tensor最后一维的通道数
    • bias: bool型， Linear线性变换中是否添加bias偏置

  3. nn.Linear()的执行：（即执行forward函数）
    out=nn.Linear(input)

  • input: 表示输入的Tensor，可以有多个维度
  1. 举例：2维 Tensor

    x.view()
    view操作用于将批量数据展平，使得每个样本的所有特征参数排列在一维向量中，便于后续计算。

代码内容理解

经过上面的基础知识，我们来详细看一下图像的变化过程，代入函数中的参数，看一下这段代码是在干什么：

  1. 比如输入一个手写数字“5”的图像，它的维度为（batch,1,28,28）即单通道(1层，彩色图片3层),28X28大小。
  2. 首先通过一个卷积核为5×5的卷积层，其通道数从1变为10，高宽分别为24像素。
  • 这里参考上面卷积层基础内容中的一张图，通道数围为1的手写数字“5”（28x28）,分别和通道数为10的卷积核(5x5)相乘，得到通道数为10的结果1（24x24），这里的24是因为卷积核从左到右，步长为一的移动时，只能移动24步，从上到下也是同理，也就是卷积运算的结果为24x24
  1. 然后通过一个卷积核为2×2的最大池化层，通道数不变，高宽变为一半，即维度变成（batch,10,12,12）；
  • 现在图片维度为(batch,10,24,24),经过池化层，24x24/2x2得到12x12，通道数不变
  1. 然后再通过一个卷积核为5×5的卷积层，其通道数从10变为20，高宽分别为8像素；
  2. 再通过一个卷积核为2×2的最大池化层，通道数不变，高宽变为一半，即维度变成（batch,20,4,4）；
  3. 之后将其view展平，使其维度变为320(20x4x4)之后进入全连接层，用线性函数将其输出为10类，即“0-9”10个数字。
    根据上面的举例：2维 Tensor 这里是先将(batch,320)和(320, 50)矩阵相乘得到(batch,50)
    再把(batch,50)和(50,10)相乘得到(batch,10)的矩阵结果，即得到我们batch个案例内的10个对应0-9的结果

至此，所有的网络模型已经搭建完成

损失函数和梯度下降

torch.nn.CrossEntropyLoss()

torch.nn.CrossEntropyLoss(weight=None, size_average=None, ignore_index=-100, reduce=None, reduction=’mean’, label_smoothing=0.0)

该函数计算输入 logits 和目标之间的交叉熵损失。

optimizer = torch.optim.SGD()

SGD 是 PyTorch 中用于实现随机梯度下降（Stochastic Gradient Descent，SGD）优化算法的类。SGD 是一种常用的优化算法，尤其在深度学习中被广泛应用。下面是 torch.optim.SGD 的主要参数及其说明：

  1. params（必须参数）: 这是一个包含了需要优化的参数（张量）的迭代器，这里我们设置的是全局变量model.parameters()
  2. lr（必须参数）: 学习率（learning rate）。它是一个正数，控制每次参数更新的步长。较小的学习率会导致收敛较慢，较大的学习率可能导致震荡或无法收敛。这里我们设置的是全局变量learning_rate().
  3. momentum（默认值为 0）: 动量（momentum）是一个用于加速 SGD 收敛的参数。它引入了上一步梯度的指数加权平均。通常设置在 0 到 1 之间。当 momentum 大于 0 时，算法在更新时会考虑之前的梯度，有助于加速收敛。

训练函数

  • Step1：前馈（forward propagation）
  • Step2：反馈（backward propagation）
  • Step3：更新（update）

    epoch

使用训练集的全部数据对模型进行一次完成训练，被称之为“一代训练”。
这里是指训练数据的个数，结合主函数看，epoch从0-9一直取值，每训练一轮(10次)，就进行一次测试

running_loss

损失值

running_total

训练集中训练的个数的总和

running_correct

经过模型分类后正确的个数

batch_idx

batch是训练集中的一小部分样本对模型权重进行一次反向传播的参数更新
这里的batch_idx是这批样本的索引

for batch_idx, data in enumerate(train_loader, 0):

enumerate() 函数用于将一个可遍历的数据对象(如列表、元组或字符串)组合为一个索引序列，同时列出数据和数据下标，一般用在 for 循环当中。:enumerate(sequence, [start=0])
这里是讲训练集从头开始迭代，将索引序列放在batch_idx中，数据放在data中

inputs, target = data

  • inputs是个包含数据的变量，labels是个包含数据标签的变量，这个表达式”inputs,labels = data”意味着将data中的数据分别赋值给inputs和labels.
  • 具体来说，data是一个包含了训练样本数据和对应标签的数据集。假设data是一个二维数组，其中每一行代表一个样本数据，而最列代表该样本的标签。那么此表达式将会将data的前N-1列赋值给inputs变量(N为data的列数)，将最后一列赋值给labels变量,
  • 举个例子，假设data是以下二维数组:
    data = [[1, 2, 3], [4,5, 6], [7,8, 9] ]
    那么经过”inputs,labels =data”操作后，inputs将会变成以下 变量:
    nputs =[[1, 2], [4, 5],[7,8]]
    而labels将会变成以下变量
    abels = [3, 6, 9]
    这样，我们可以利用inputs变量来表示训练数据，用labels变量来表示对应的标签数据。

outputs = model(inputs)

这里的model就是刚刚建立的CNN模型

loss = criterion(outputs, target)

loss.backward()

参数更新

predicted = torch.max(outputs.data, dim=1)

torch.max()返回元素中的最大值及其索引

inputs.shape[0]是指这一次输入的图片的个数

running_correct += (predicted == target).sum().item()

当预测值等于真实值，即预测成功，running_correct累加，这里的sum是指这一组数据的正确个数的和
